# Workforce Planning & SLA Risk Dashboard

## Overview
This project analyses whether incoming workload exceeds team capacity and how that impacts backlog, SLA performance, and hiring needs.

## Problem
Operations teams often react after performance drops. This project helps identify problems early:
- When demand exceeds capacity
- When backlog becomes dangerous
- When SLA is at risk
- When hiring is needed

## Key Results
- Peak backlog: 564 claims
- Max capacity gap: 30 claims
- 37 days at SLA risk
- 37 days needing hiring
- ~20% of time had operational risk
